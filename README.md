## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deploy to Vercel

1. Push the project to GitHub.
2. Import the GitHub repository into Vercel.
3. Choose Vite as the framework preset.
4. Use `npm run build` as the build command.
5. Use `dist` as the output directory.
6. Deploy.
